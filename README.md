# skilllab

## Login and User Management Dashboard

A web app with a validated login page, a user table fetched from a public REST API (GET, POST), search, and add/delete features. It uses localStorage to keep the login session and table data after a refresh.

## Tech
HTML, CSS, JavaScript, REST API (randomuser.me, jsonplaceholder), localStorage

## Run
Open `index.html` with VS Code Live Server.
